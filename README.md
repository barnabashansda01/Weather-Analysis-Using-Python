# 🌦️ Weather Data Analysis Using Python

This project focuses on analyzing and exploring a **Weather Dataset using Python and Pandas**. The dataset contains hourly weather observations with information such as temperature, dew point temperature, relative humidity, wind speed, visibility, atmospheric pressure, and weather conditions.

The project demonstrates practical **Exploratory Data Analysis (EDA)** techniques to understand the structure, characteristics, and patterns within the weather data.

## 📊 Dataset Overview

* **Records:** 8,784
* **Columns:** 8
* **Data Type:** Hourly weather observations
* **Weather Categories:** 50 unique conditions

### Dataset Features

* `Date/Time` – Date and time of observation
* `Temp_C` – Temperature in Celsius
* `Dew Point Temp_C` – Dew point temperature
* `Rel Hum_%` – Relative humidity
* `Wind Speed_km/h` – Wind speed
* `Visibility_km` – Visibility
* `Press_kPa` – Atmospheric pressure
* `Weather` – Weather condition

## 🔍 Analysis Performed

The project includes:

* Loading the weather dataset using Pandas
* Understanding dataset shape and structure
* Checking rows, columns, and data types
* Identifying unique and distinct values
* Counting values and occurrences
* Analyzing different weather conditions
* Finding unique wind-speed values
* Identifying the frequency of specific weather conditions
* Checking missing/null values
* Performing basic exploratory analysis
